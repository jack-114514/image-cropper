# Changelog

## 0.1.1 — 2026-10-01

- Neutral project name, package identity, styles and standalone demo branding.
- Public distribution as Image Cropper, with independent installation and documentation.

## 0.1.0 — 2026-10-01

- Independent React/TypeScript image cropper package with no website or backend dependency.
- Rectangle/circle stencils, free/fixed ratios and local browser processing.
- Continuous panning at preview edges, invisible handles and circle circumference resizing.
- PNG/JPEG/WebP Blob export, output size limits and optional transparent circle PNG.
- Percentage selection save/restore, imperative API and English/Chinese labels.
- Upload/download demo with original sample artwork, documentation and automated checks.
